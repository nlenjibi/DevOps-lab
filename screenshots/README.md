# Screenshots folder

This folder should contain the screenshot files referenced by `SCREENSHOTS.md`.

Expected filenames (place PNGs here):

- `app-running.png`
- `test-output.png`
- `docker-ps.png`
- `ci-pipeline.png`
- `lint-output.png`

Example Markdown to embed an image in `README.md` or `SCREENSHOTS.md`:

```markdown
![App running](screenshots/app-running.png)
```

Please add actual screenshots (PNG) with the filenames above and commit them.
